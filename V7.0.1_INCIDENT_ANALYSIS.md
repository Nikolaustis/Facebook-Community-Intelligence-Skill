# V7.0.1 Incident Analysis

## Symptom

Phase 1 completed normally and login validation passed, but every search variant ended with `NO_NEW_GROUPS_3_SCROLLS` and `total_candidates: 0`, while the same account could see many groups when searching manually.

## Determination

This is a false-zero Phase 1 extraction failure, not proof that Facebook returned no groups. V6.6.4 relied on four brittle assumptions:

1. the useful group title was the `innerText` of the group link itself;
2. the result used the global `/search/groups/` surface;
3. the result was ready after a fixed 4.5-second wait;
4. the extracted card text had to contain a token derived from the query.

Facebook can render the image link, title heading, metadata, and navigation target in separate DOM nodes. It can also route different accounts to different search surfaces. Under those layouts, visible results existed but `collectRound()` returned an empty array. For `the_tower`, the old token logic also discarded `the` as a stop word and required the remaining token `tower` to appear inside the text extracted from the same link/card.

## V7.0.1 correction

- groups all DOM links by canonical group URL before selecting a name;
- extracts names from same-URL links, headings, `aria-label`, `title`, and nearby card lines;
- keeps Facebook-returned group URLs at Phase 1 even when the visible card text omits the query token;
- records the token match as audit metadata instead of using it as a hard rejection;
- waits for an actual group link or terminal page signal rather than only sleeping 4.5 seconds;
- retries through a second Facebook group-search route when the first exposes no group links;
- scrolls both the document and the largest detected scroll container;
- distinguishes login/checkpoint, temporary Facebook error, genuine no-result text, raw links present, and extractor zero;
- writes JSON, HTML, and screenshot diagnostics whenever a query still ends at zero.

Phase 1.5 remains responsible for name relevance. The high-recall Phase 1 change therefore does not mean all discovered links are retained in the final workbook.
