## Regression guard

The package contains a static assertion that the scheduled runner does not invoke the supervisor with:

```text
1>> $StdoutLog 2>> $StderrLog
```

The expected invocation uses:

```text
1>> $SupervisorStdoutLog 2>> $SupervisorStderrLog
```

The runner also records all four log paths in status output.

## Environment limitation

The container cannot execute Windows Task Scheduler or Windows PowerShell 5.1. The exact Windows file-sharing behavior was validated from the uploaded incident evidence and the user's successful local minimal fix; the packaged scripts were additionally checked statically and through the cross-platform Node supervisor integration test.
