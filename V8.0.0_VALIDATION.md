# V8.0.0 validation checklist

Before recreating the GitHub Release/tag `V8.0.0`, run the following from the complete repository after applying this overlay:

```powershell
npm ci
npm run doctor
npm test
```

Expected release-version contract:

- `package.json` => `8.0.0`
- `package-lock.json` root package => `8.0.0`
- `SKILL.md` frontmatter => `8.0.0`
- the verified Phase 1 runtime wrapper emits diagnostic `version: 8.0.0`
- generated `phase1_index.json` emits `skill_version: 8.0.0`
- `npm run release-version:test` passes

The V8.0.0 release must remain Game-centric. Subject/Community/Match, Community Intelligence, benchmark, AI-evaluation, and V2 example folders belong to the next major release and should not be mixed into this historical baseline.
