# V6.6.3 Incident Analysis

## Incident

A King Legacy phase-2 run passed input validation and Facebook login checks, but the scheduled startup repeatedly failed with:

```text
System.Management.Automation.RemoteException: node:events:486
```

The CDP endpoint remained available, so the failure was not caused by Facebook authentication or Chrome startup.

## Root cause

The PowerShell scheduled runner launched `phase2_supervisor.js` with its process stdout and stderr redirected to the same main files that were simultaneously passed to the supervisor through:

```text
--stdout-log
--stderr-log
```

The supervisor then opened those files with `fs.createWriteStream()` to pipe the phase-2 child output. Windows PowerShell and Node therefore held competing append handles to the same paths. On the affected Windows environment the Node write stream failed before a reliable progress checkpoint could be established.

The uploaded incident log recorded three immediate `node:events:486` failures. The uploaded supervisor source confirms that it opens and owns the child log files. The subsequent local minimal patch, which redirected the supervisor wrapper to separate logs, passed startup health checks.

## Correction

V6.6.3 creates four distinct log files per scheduled launch:

```text
scheduled_phase2_<timestamp>.stdout.log
scheduled_phase2_<timestamp>.stderr.log
phase2_supervisor_<timestamp>.stdout.log
phase2_supervisor_<timestamp>.stderr.log
```

The first pair belongs to the phase-2 child through the supervisor. The second pair belongs to the PowerShell invocation of the supervisor itself.

Additional defense:

- manifest version 6 records all four paths;
- the runner rejects path collisions by replacing them with distinct fallback paths;
- supervisor log-open and stream failures are caught and written to runner status;
- startup still requires a fresh readable progress checkpoint.

## Scope

This incident was a Skill startup implementation defect. It was not caused by Facebook login, candidate data, GeoNames, semantic providers, or the user's Windows configuration.
