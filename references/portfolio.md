# Portfolio framing

This repository is structured as an engineering case study rather than a one-off crawler.

Demonstrable areas:
- Subject / Community / Match many-to-many domain modeling;
- automatic migration from existing `games` configuration;
- canonical Community identity and evidence reuse;
- reliable checkpoints and foreground/background entrypoints;
- golden regression, 120-case synthetic benchmark, and AI evaluation harness;
- machine-readable run manifests;
- demo datasets and CI regression gates;
- Facebook Groups source adapter without unsupported multi-source claims.

In a resume or interview, distinguish implemented capability, synthetic benchmark results, and future source-adapter work.
