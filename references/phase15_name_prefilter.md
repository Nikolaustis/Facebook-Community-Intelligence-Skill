# Phase 1.5 群名预筛规范

## 目标

在第二轮打开 Facebook About 或讨论页之前，对第一轮全部候选群名做一次离线遍历，排除明确无关项，降低页面访问量、运行时间和中断风险。

## 使用的证据

按以下信息综合判断：

1. 游戏完整标题。
2. 配置别名。
3. 配置扩展检索词。
4. 候选实际来源检索词。
5. 安全的标题空格、标点和完整标题形态变化。
6. 兄弟游戏标题、别名及配置变体。
7. IP root（默认只作为弱证据，不足以单独放行）。

## 默认处理规则

- 完整标题、有效别名或有效来源检索词在群名中独立出现：保留。
- seed URL：保留并进入页面核验。
- 缺失或明显截断的群名：保留为待核验项。
- 只有 IP root：默认拒绝。
- 只有兄弟游戏证据：默认拒绝。
- 较短目标只嵌在更具体兄弟标题中：拒绝。
- 一个群名独立包含多个目标游戏时，可分别在各目标游戏下保留。

## 混合文字边界

当目标短语只包含拉丁字母和数字时，中文、泰文、老挝文、阿拉伯文、韩文、西里尔文等非拉丁文字可直接连接在英文标题前后，不要求显式空格。

例如：

```text
Sailor Piece水手寶石中文交易討論區
All Star Tower Defenseซื้อขายแลกเปลี่ยน
ซื้อขายPet Simulator 99
GAG中文交易群
```

以下拉丁或数字续接不能作为目标命中：

```text
Sailor Pieces
Sailor PieceMN
All Star Tower DefenseX
Pet Simulator 99100
GAG2（不能作为 GAG）
9GAG（不能作为 GAG）
```

标题词之间允许 Unicode 格式控制符（例如零宽空格），以兼容 Facebook 页面中的隐藏排版字符。

## 输出与缓存

Phase 1.5 必须写出缩减索引、按游戏候选文件、审计、拒绝清单、待复核清单、缓存 manifest 和进度文件。原始 `phase1_index.json` 与原始候选 JSON 不得被覆盖。
