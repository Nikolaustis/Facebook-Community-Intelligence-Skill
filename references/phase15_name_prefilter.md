# Phase 1.5 群名预筛规范

## 目标

在第二轮打开 Facebook About 或讨论页之前，对第一轮全部候选群名做一次离线遍历，排除明确无关项，降低浏览器访问量、运行时间和中断风险。

## 历史数据依据

用户提供的 2026.4—2026.7 工作簿包含 7,501 条最终保留记录、62 个游戏。

- 7,262 条（96.8138%）可由完整游戏名或去标点/合并空格后的标题直接命中。
- 其余合法模式主要是配置缩写、当地语言标题、末词单复数变化、连接词省略和已配置扩展检索词。
- 旧记录也包含 `GAG` 与 `GAG2`、`gags`、`gagged` 等边界误收，因此不能使用简单 compact substring。

## 证据优先级

1. 完整标题。
2. 配置别名。
3. 配置扩展检索词。
4. 候选实际来源检索词。
5. 安全的标题形态变化。
6. IP root（仅审计，默认不足以放行）。

## 保守原则

- 缺名、截断名和 seed URL 不在 Phase 1.5 丢弃。
- 本地译名必须来自配置别名/扩展词或候选实际 source query，不能自动猜译。
- 多游戏群名只要目标证据独立存在即可保留。
- 较短目标若只嵌在更具体兄弟标题中则丢弃。
- 预筛结果必须可审计、可缓存、可重建，原始候选文件不得覆盖。
